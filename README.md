# NexShop-BD E-Commerce Platform 🛒🇧🇩

NexShop-BD is a modern, full-stack E-Commerce web application being developed with **Django**, **Python**, **MySQL (Clever Cloud)**, and **Bootstrap UI**.

## ✨ Planned Key Features
- 🔐 **User Authentication:** Secure Registration, Login, Hashed Passwords, Session Management.
- 🛍️ **Product Catalog:** Responsive product cards, category sidebar filters, dynamic pricing.
- 🔍 **Search Engine:** Real-time search query matching product titles and descriptions.
- 🛒 **Shopping Cart:** Add/Remove items, dynamic quantity adjustment, live subtotal calculations.
- 💳 **Checkout System:** Order creation with shipping details and payment status tracking.
- 🚚 **Order History:** Real-time order status tracking (Pending, Shipped, Delivered).
- ⚙️ **Admin Dashboard:** Customized Django admin panel with status filters and quick verification actions.

---

## 🛠️ Technology Stack
- **Backend:** Django 3.1+, Python 3.10
- **Frontend:** HTML5, CSS3, Bootstrap 4/5, JavaScript
- **Database:** MySQL / PostgreSQL (Clever Cloud)
- **Deployment:** Render PaaS (In Progress)
- **CI/CD:** GitHub Actions Automated Quality Checks
